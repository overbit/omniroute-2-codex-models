# Contributing

Issues and pull requests are welcome. For bugs, include your Node.js version, deployment method, sanitized configuration, upstream response shape (remove secrets), and expected versus actual behavior.

1. Fork the repository and create a focused branch.
2. Run `npm test` and `node --check proxy.js`.
3. Use Conventional Commits (`fix:`, `feat:`, `docs:`, `test:`, `chore:`), keeping commits atomic.
4. Open a pull request explaining the change and how it was tested.

Never post credentials or private model catalogs. Be respectful and constructive.
